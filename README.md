# OC-Project-7-Algorithm-Big-O

Open Classroom's Python course [7th project](https://openclassrooms.com/fr/paths/879/projects/836) about optimizing an algorithm to select the best actions to buy to maximize profits for an imaginary wallet.

---

### Requirements:

- Having Python3 installed.
- Downloading this repository and getting the project open in the IDE of your choice.

---

### Steps to run this code are:

Creating the virtual environment:

```
python -m venv .venv
```

Activating said environment:

```
source .venv/bin/activate
```

Install required libraries (pandas here):

```
pip install -r requirements.txt
```

---

Then run which script you want with:

```
python bruteforce.py
```

or:

```
python optimized.py
```
